3D Grid-Based Puzzle Game

A 3D grid-based puzzle game developed using Unity and C#. The game features dynamic grid generation, tile selection, cube spawning, different cube types, and grid-based movement.

Features

Dynamic grid generation using adjustable width and height.

Select tiles using the mouse.

Spawn cubes using the Space key.

Different cube types using ScriptableObjects.

Use W, A, S, D keys to move cubes.

Cubes cannot move outside the grid.

Cubes cannot move onto tiles already occupied by another cube.
